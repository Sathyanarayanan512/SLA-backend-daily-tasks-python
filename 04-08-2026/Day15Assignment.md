do analysis on list, tuple, set and dict datatypes. write the characteristics of each collection datatype



1\. List:

* Ordered
* Changeable or mutable - dynamically sized
* Allows duplicate elements
* Indexed and allows slicing of elements
* Supports multiple datatypes within a single list



list\_name=\[element1, element2,...., elementn]



2\. Tuple:

* Ordered
* Unchangeable or immutable - not dynamically sized
* Allows duplicate elements
* Indexed and allows slicing of elements
* Supports multiple datatypes within a single tuple



tuple\_name=(element1, element2,....., elementn)



3\. Set:

* Unordered
* Changeable or mutable - dynamically sized
* Doesn't allow duplicate elements
* Not indexed and doesn't allow slicing
* Supports multiple datatypes within a single set



set\_name={element1, element2,......, elementn}



4\. Dictionary:

* Ordered(Python 3.7+)
* Changeable or mutable - dynamically sized
* Allows duplicate elements
* Not indexed and doesn't allow slicing
* Supports multiple datatypes for values, key must be of immutable type



dict\_name={key1: value1, key2: value2,....,keyn: valuen}
