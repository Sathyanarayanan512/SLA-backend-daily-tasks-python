write about types of inheritance in python



There are 5 types of inheritance in python:



1\. Single inheritance:

* This is the basic type of inheritance where a class is derived or inherited from a single parent or base class.
* It represents one to one relationship.
* Parent class -> Child class



2\. Multiple inheritance:

* Here a single child class is derived or inherited from multiple parent or base classes.
* It represents many to many relationship.
* Parent class1, Parent class2,... -> Child class



3\. Multilevel inheritance:

* Here a single derived class that is derived from a parent class, acts as a parent or base for another derived class.
* It represents a chain of relationships(between classes)
* Parent class1 -> Derived class1 -> Derived class2



4\. Hierarchical inheritance:

* Here multiple child classes are inherited from a single parent or base class.
* It represents one to many relationship.
* Parent class -> Child class1, Child class2,...



5\. Hybrid inheritance:

* It is a combination of one or more of the remaining 4 types of inheritances.
* Example: Multiple and multilevel inheritance occurring simultaneously
